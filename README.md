# FreshMart

FreshMart is a modern grocery shopping frontend built with React, Redux Toolkit, React Router, and Tailwind CSS.

## Features

* Browse grocery products
* Search products
* Filter products by category
* View product details
* Add and remove favorites
* Add products to cart
* Update cart quantities
* Free delivery calculation
* Checkout form with validation
* Place orders
* View order confirmation
* View previous orders
* Track order status
* Responsive design
* LocalStorage persistence for cart, favorites, and orders

## Tech Stack

* React
* Vite
* React Router
* Redux Toolkit
* React Redux
* Tailwind CSS
* Lucide React

## Getting Started

Clone or download the project, then install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Run ESLint:

```bash
npm run lint
```

Create a production build:

```bash
npm run build
```

## Project Structure

```text
src/
├── app/

```

## Data

FreshMart is currently a frontend-only application. Product, category, cart, favorite, and order data are handled on the client side, with relevant data persisted in LocalStorage.
